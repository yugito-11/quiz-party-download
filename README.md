# 🎲 Quiz Party – Download

Quiz-Abende im Stil von Jeopardy und Factile: Du bist der Gamemaster, deine Freunde spielen im Browser mit, am Handy oder am PC.

## ⬇ Herunterladen (Windows)

**[Quiz Party herunterladen (QuizParty-Setup-1.62.11.exe)](https://github.com/yugito-11/quiz-party-download/raw/main/QuizParty-Setup-1.62.11.exe)**

1. Die Datei herunterladen und doppelklicken – der Installer richtet Quiz Party ein und legt eine Verknüpfung an.
2. Quiz Party startet danach in einem eigenen App-Fenster. Schließt du das Fenster, wird Quiz Party beendet.

> **Windows-Hinweis:** Beim ersten Start erscheint eventuell „Der Computer wurde durch Windows geschützt“.
> Klick auf **„Weitere Informationen“** und dann **„Trotzdem ausführen“**.
> Ein Fenster der Windows-Firewall fragt eventuell, ob Quiz Party im Netzwerk erreichbar sein darf.
> Bestätige mit **„Zulassen“** (private Netzwerke reichen), damit deine Freunde mitspielen können.

## Mitspielen

Deine Freunde brauchen **nichts zu installieren**. Sie öffnen im Browser (Handy oder PC)

**https://yugito-11.github.io/quiz-party-download/**

und geben den PIN ein, den Quiz Party zeigt – oder sie scannen einfach den QR-Code.
Das klappt überall: im selben WLAN, über mobiles Internet oder per Discord.

## Updates

Gibt es eine neue Version, erscheint im Gamemaster **„Neue Version verfügbar“**.
Ein Klick auf **„Jetzt aktualisieren“** genügt, und Quiz Party startet neu.
Deine Quizzes liegen unter **Dokumente → Quiz Party** und bleiben bei Updates erhalten.

## Stream Deck

Im Gamemaster gibt es den Knopf **„🎛 Stream-Deck-Plugin installieren“**.
Voraussetzung ist die Stream-Deck-Software 7.1 oder neuer.

## Android-App „Quiz Steuerung“
Handy/Tablet als Steuerpult ohne Browser-Leiste: [QuizParty-Steuerung.apk](QuizParty-Steuerung.apk) – oder direkt in Quiz Party über „Handy“ per QR-Code laden.
